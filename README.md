## Projects

### 1. NLP Multi-Class Intent Classifier for AI Assistant
- **Challenge:** Robustly classify 77 fine-grained banking intents to power next-gen chat assistants.
- **Impact:** Improved production intent detection accuracy to **90.6%** (vs. ~65% baseline industry chatbots). Confident OOD rejection.
- **Highlights:** DistilBERT, full error analysis, heatmap visualization, OOD handling, rapid retraining supported.
- [See the project folder for full details](https://github.com/rhishikumarayyappan/NLP-Projects/tree/main/NLP_Multi_Class_%20Intent%20_Classifier_%20for_AI_%20Assistant)

### 2. BART-TextRank Hybrid for News Summarization
- **Challenge:** Summarize lengthy news articles into concise, accurate stories for fast content consumption.
- **Impact:** Raised ROUGE-1 to **0.70** and BERTScore to **0.95** (vs. pure extractive: <0.50), enabling quick, faithful news digests.
- **Highlights:** BART transformer + TextRank hybrid pipeline, FastAPI demo, BERTScore/METEOR/ROUGE, multi-dataset, production scoring modules.
- [See the project folder for full details](https://github.com/rhishikumarayyappan/NLP-Projects/tree/main/NLP_BART_TextRank_Hybrid_News_Summarization)

### 3. NLP Open Source RAG QA Notebook
- **Challenge:** Open-source, efficient document context-retrieval and question answering with LLMs.
- **Impact:** Delivers grounded, explainable answers via RAG, **3.3–11.8s**/QA, robust to out-of-context queries, easy for any business corpus.
- **Highlights:** Mistral-7B (4bit), MiniLM embeddings, FAISS retrieval, Sherlock Holmes QA demo, t-SNE visualization shows semantic clusters.
- [See the project folder for full details](https://github.com/rhishikumarayyappan/NLP-Projects/tree/main/NLP_Open_Source_RAG_QA_Notebook)
