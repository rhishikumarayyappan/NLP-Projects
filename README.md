## Projects

### 1. NLP Multi-Class Intent Classifier for AI Assistant
- **Challenge:** Robustly classify 77 fine-grained banking intents to power next-gen chat assistants.
- **Impact:** Improved production intent detection accuracy to **90.6%** (from ~65% industry chatbot baseline), confidently rejects out-of-domain queries.
- **Highlights:** DistilBERT, full error analysis, heatmap visual, OOD handling, support for rapid retraining.
- [See the project folder for full details](./NLP_Multi_Class_Intent_Classifier_for_AI_Assistant)

### 2. BART-TextRank Hybrid for News Summarization
- **Challenge:** Summarize lengthy news articles into concise, digestible stories for content consumption.
- **Impact:** Elevated ROUGE-1 to **0.70** and BERTScore to **0.95** (vs. pure extractive: <0.50), automating quick and faithful news digests.
- **Highlights:** BART transformer + TextRank hybrid, FastAPI demo, BERTScore/METEOR/ROUGE, multi-dataset, production scoring pipeline.
- [See the project folder for full details](./BART-TextRank-Hybrid-for-News-Summarization)

### 3. NLP Open Source RAG QA Notebook
- **Challenge:** Open-source, efficient context-retrieval and free-form text QA with LLMs over unstructured data.
- **Impact:** Delivers grounded, explainable answers using RAG, **3.3–11.8s** per QA, robust to out-of-context queries, easy for any business document corpus.
- **Highlights:** Mistral-7B (4bit), MiniLM embeddings, FAISS retrieval, Sherlock Holmes QA demo, t-SNE visualization.
- [See the project folder for full details](./NLP_Open_Source_RAG_QA_Notebook)
